#我會把 JPEG AI 及 Github 使用上遇到的問題都寫下來

#使用 pull/push 的方式 :
#   每次更改程式前先 : git pull origin main (確保使用的是最新版本再開始編輯)
#   每當有更改檔案時 : git add . (將全部檔案加入暫存區)
#   git commit -m "change note.html to  note.txt" (將檔案寫上備註並提交)
#   git push origin main (把當案合併到原始檔(注意使用 add . 會覆蓋所有檔案 可以使用 git add <file> 代替))

#使用 branch 的方式 :
#   git branch 查看當前位於哪一個branch(盡量不要直接修改 main ，錯誤時比教容易更正)
#   git checkout <branchname> (切換 branch)
#   git checkout -b feature/note (在本地創建新的 branch)
#   創建 branch 前可能要先確認 branch 有沒有被認可，確認更改完程式後從第10行的部分繼續執行

# merge 的方法 :
#   git checkout main (切回 main)
#   git pull origin main (確認使用的 main 為最新版本)
#   git merge feature/note (將想要合併的 branch 合併到 main 中)
#   git commit -m "merge" (確認並提交)
#   git push origin main (上傳正式版)

#9/12心得 :
#   養成好習慣每次開始前先 git branch 確認分支， git pull 確認工作的版本為最新版
